# 终焉花海

重写后的远古Python作业。

## 运行

需要Python3.14及[uv](https://docs.astral.sh/uv/guides/projects/)。在项目目录执行：

```sh
uv run main.py
```

uv将根据`pyproject.toml`和`uv.lock`管理项目虚拟环境。游戏依赖[pygame-ce](https://pyga.me/docs/)，代码中的导入名为`pygame`。

- 标题页面：点击鼠标左键开始。
- 战斗：方向键或WASD移动，按住鼠标左键射击。
- 左Shift：慢速移动，显示判定点。
- F1：显示碰撞区域；F2：输出调试状态。
- 结算页面：点击鼠标左键退出。

窗口大小为1280×720。
